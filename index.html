XIRR Calculator

Calculate the annualised return when investments and withdrawals happen on different dates.

How to use

  1. Add every investment with its actual date.
  2. Add withdrawals or today's portfolio value as “Return / Current Value”.
  3. Select “Calculate XIRR” to see the annualised return.

Easy entry: Investment = पैसा लगाया. Return / Current Value = मिली हुई या आज की कुल राशि.
